# C 代码规范检查

## What it does

[c-code-standards](../../skills/engineering/c-code-standards/SKILL.md) 在编写或修改 C 源码及头文件时，依据 MISRA C:2012、定制 BARR-C:2018、K&R 排版和中文 Doxygen 注释要求进行检查。仅阅读、讨论或审查而未编写代码时跳过。

## When to reach for it

编写或修改 C 代码时可显式调用，也可由支持自动调用的平台按描述选择。插件中的钩子在会话开始、用户发消息和子代理开始时注入技能正文，是否运行取决于平台支持与钩子信任设置。

## Common questions

**这能证明代码完全符合 MISRA 或 BARR 吗？** 不能。正式合规需要授权的标准全文、合规计划、工具报告及偏差记录；技能要求如实说明检查覆盖范围。

**非 C 任务会执行检查吗？** 不会。钩子加载规范时，技能仍要求仅在本轮实际编写或修改 C 代码时应用。

## It's working if

- 修改 C 代码前识别适用规范，完成后检查本轮差异并报告实际验证与偏差。
- 只读讨论或非 C 任务不输出无意义的规范检查报告。
